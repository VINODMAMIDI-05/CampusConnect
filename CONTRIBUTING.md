````md
### 1. Clone the repository

```bash
git clone <repository-url>
cd CampusConnect
```
````

### 2. Check the current state

```bash
git status
```

### 3. Create a new branch

Do not directly work on `main`.

```bash
git switch -c feature/my-feature
```

Examples:

```text
feature/events
feature/dark-mode
feature/contact
feature/responsive-design
fix/mobile-navigation
docs/improve-readme
```

### 4. Make your changes

Edit the required HTML, CSS or JavaScript files.

### 5. Test your changes

Check:

- Desktop layout
- Mobile layout
- Navigation
- Links
- JavaScript functionality

### 6. Stage changes

```bash
git add .
```

### 7. Commit

Use a meaningful message:

```bash
git commit -m "Added event filtering"
```

### 8. Push your branch

```bash
git push -u origin feature/my-feature
```

### 9. Create a Pull Request

Open the GitHub repository and create a Pull Request from your branch to `main`.

### 10. Review

A maintainer may:

- Approve your PR
- Ask for changes
- Comment on the code

### 11. Merge

After approval, the maintainer can merge the Pull Request.

## Important Rules

- Do not directly push to `main`.
- Keep Pull Requests small and focused.
- Use clear commit messages.
- Never commit passwords, PATs, API keys or other secrets.
- Pull the latest `main` before starting major work.
