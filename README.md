# CampusConnect

A small student community website built with **HTML, CSS and Vanilla JavaScript**.

This project is intentionally designed as a hands-on **Git + GitHub collaboration project**.

## Features
a

- Responsive student community website
- Events page
- Announcements page
- Contact form validation
- Search and category filtering
- Light/dark mode
- Mobile navigation
- Beginner-friendly code

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

Clone the repository:

```bash
git clone <repository-url>
cd CampusConnect
```

Then open `index.html` in your browser.

No backend or package installation is required.
